## 🎨 UI/UX Features & Design System

- **Dark Mode Cyberpunk Aesthetic**: High-contrast dark canvas (`#0b0f17`) with ambient gradient orbs and cyber accents (`#00f2fe` electric cyan, `#9d4edf` cyber purple, and `#10b981` emerald green).
- **Engineering DNA Pipeline**: Custom 3-stage process grid (*"What Makes Me Extraordinary?"*) breaking down product discovery, deep architecture, and iterative refinement.
- **Live App Pulse Badges**: Concentric radar ping status badges on active production apps.
- **1-Click Copy Email**: Tactile clipboard copy button with visual badge feedback and fallback support.
- **Interactive Hero Elements**: Animated mouse wheel scroll-to-explore indicator and simulated Python developer profile code window (`developer_profile.py`).
- **Fluid Typography**: Dynamic `clamp()` scaling ensuring balanced headers from 320px smartphones to 4K monitors.
- **Custom Branding**: Bespoke `<AT/>` SVG browser favicon and comprehensive Open Graph & Twitter Card social meta tags.
